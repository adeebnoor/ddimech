# Drug-Drug Interaction mechanisms and ACI 2026 reproducibility assets

This repository contains historical DDI mechanism code and the public reproducibility assets for the 2026 Applied Clinical Informatics manuscript:

**Clinical Relevance Over Statistical Association: An Interpretable Probabilistic Layer for Prioritizing Drug-Drug Interaction Alerts**

The submission-specific materials are in `aci2026/`.

Important boundary: the full continuous-feature matrix and some source-level clinical-reference material depend on licensed DrugBank/UMLS or commercial-reference content and are not redistributed here. The repository therefore exposes the evaluation harness and non-restricted derived summaries needed to inspect the evaluation design and reported aggregate results.

Nothing in this repository is a prescribing recommendation or a substitute for current clinical drug-interaction resources.
